# Лабораторна робота №1. Аудит власної цифрової безпеки

Програма аналізує пароль на зв'язок з персональними даними
(ім'я, прізвище, нік, дата народження) та оцінює його від 1 до 10.

## Як запустити
1. Встановити Python 3.
2. Запустити: `python password_checker.py`
3. Програма покаже результати для 5 тестових паролів,
   потім можна ввести власний пароль (Enter - вийти).

## Що перевіряє програма
- довжину пароля
- наявність імені, прізвища або ніка
- наявність частин дати народження
- словникові слова
- великі й малі літери, цифри, спеціальні символи
