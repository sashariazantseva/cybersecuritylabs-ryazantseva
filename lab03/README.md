# ЛР3. Невидимі дані у власних файлах

**Автор:** Рязанцева Олександра Сергіївна, гр. 6.04.122.010.23.3

Програма ховає текст у зображенні методом LSB (заміна молодшого біта кольору),
витягує його назад, порівнює оригінал і стегоконтейнер, шукає приховані дані
в чужих картинках і показує та очищує метадані EXIF.

## Можливості

| Вкладка | Що робить |
|---|---|
| 1 · Як це працює | текст -> UTF-8 -> біти -> молодші біти пікселів, покроково |
| 2 · Сховати / витягти | `hide_message()` і `extract_message()`, вибір каналів R/G/B, шифрування Віженером |
| 3 · Аналіз змін | кількість змінених пікселів, зміни по каналах, PSNR, карта відмінностей |
| 4 · Пошук прихованого | площина молодших бітів, частка одиниць, атака хі-квадрат, пошук маркерів |
| 5 · Метадані EXIF | показ EXIF фото з телефона (модель, дата, GPS) і очищення |

Маркери: `ST3G` на початку і `\0END` в кінці повідомлення.
Готові бібліотеки стеганографії не використовуються, Pillow - тільки для читання і запису пікселів.

## Запуск

```bash
pip install -r requirements.txt
python app.py                       # програма з вікном
python demo.py                      # усе без вікна, результати в results/
python demo.py IMG_5079.HEIC        # + аналіз EXIF власного фото
python -m unittest -v test_stego.py # 10 тестів
```

## Файли

```

images/         cover.png (оригінал), stego.png (з повідомленням), external/ (фото з Unsplash)

```

Оригінальне фото з телефона (з GPS) у репозиторій не додано, лише очищена копія `results/IMG_5079_clean.jpg`.
