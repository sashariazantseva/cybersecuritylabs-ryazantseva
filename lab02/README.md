# ЛР2. Захист особистих повідомлень

**Автор:** Рязанцева Олександра Сергіївна, гр. 6.04.122.010.23.3
**Дисципліна:** «Захист інформації», ХНЕУ ім. С. Кузнеця

Програма демонструє й порівнює класичні шифри: **Цезаря**, **Віженера** та **афінний**.
Ключі генеруються з персональних даних. Є також криптоаналіз: brute force з автоматичним
вибором кандидата методом χ² і частотний аналіз з графіками.

## Можливості

| Вкладка | Що робить |
|---|---|
| 1 · Шифрування | Шифрує власний текст трьома методами й перевіряє, що розшифрування дає оригінал |
| 2 · Порівняння | Таблиця: довжина, індекс збігів (IC), % змінених літер, кількість можливих ключів |
| 3 · Brute force | Перебирає всі зсуви Цезаря (32 для UA, 25 для EN) і сам обирає правильний за χ² |
| 4 · Частотний аналіз | Гістограми частот літер до і після шифрування |
| 5 · Обмін повідомленнями | Шифрує повідомлення у файл (без ключа) і зламує отриманий шифротекст |

Підтримуються два алфавіти: український (33 літери) і латинський (26 літер).
Регістр, пробіли й розділові знаки зберігаються.

## Ключі з персональних даних

| Шифр | Правило | Значення |
|---|---|---|
| Цезар | сума цифр дати народження mod N | 1+6+0+5+2+0+0+6 = **20** |
| Віженер | прізвище | **РЯЗАНЦЕВА** / **RIAZANTSEVA** |
| Афінний | a = місяць (взаємно простий з N), b = день | **a = 5, b = 16** |

## Встановлення та запуск

Потрібен Python 3.10+ (Tkinter входить у стандартну інсталяцію Python для Windows).

```bash
pip install -r requirements.txt
python app.py                           # графічний застосунок
python demo.py                          # консольна демонстрація + збереження у results/
python -m unittest -v test_ciphers.py   # 13 автотестів
python self_exchange.py send            # самообмін: створити шифротекст
python self_exchange.py check "текст"   # перевірити результат злому
```

## Формули

- Цезар: `C = (P + k) mod N`, `P = (C − k) mod N`
- Віженер: `C[i] = (P[i] + K[i mod L]) mod N` (ключ просувається лише на літерах)
- Афінний: `C = (a·P + b) mod N`, `P = a⁻¹·(C − b) mod N`, де `НСД(a, N) = 1`

> Класичні шифри мають навчальне призначення і не підходять для реального захисту листування.
